# Speaking C\#


Outputs the SDK version
```PowerShell
dotnet --version
```

In a C# program the following will show you compiler and language versions:
```C#
#error version
```

End of statement is with a semi-colon;
A statement is composed of multiple types, variables, and expressions made up of tokens.

Each token is separated by white space or some other recognisably different token, like an operator, for example, = or +.

namespace - contains types like classes to group them together.
class - contains the members of an object, including methods.
method - contains statements that implement an action that an object can take.

Regions - self-labelled blocks of code around any statement.
	Example:

```C#
#region Three variables that store the number 2 million
int decimalNotation = 2_000_000;
int binary Notation = 0b_0001_1110_1000_0100_1000_0000;
int hexadecimalNotation = 0x_001E_8480;
#endregion
```


Prefix with @ to use a C# keyword as a variable name
```C#
string @class = "A poorly named variable!";
int @if = 5;
```


## Imports

namespace - is a container that organises and groups related classes, interfaces, structs, enums, and delegates, helping to avoid naming conflicts and making code more manageable.

Importing namespace - all available types will be available in your program without needing a prefix such as System.

```C#
using System; // Import the System namespace
```


`global` - keyword allows all imports of a namespace to one `.cs` file making the namespace available to the entire project.

Defining imports in `.csproj` file makes them generated in the `.GlobalUsings.g.cs` file generated by the compiler.


## Reflection

Reflective Programming - is a technique that allows a program to examine, introspect, and modify its own structure and behaviour

`System.Runtime` assembly contains 0 types and only has type-forwarders.
Type-forwarders - represent a type that has been implemented outside of .NET.
